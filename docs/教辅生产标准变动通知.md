# 一、教辅生产标准变动通知

## 1 针对题目题号录入标准的变更通知

1. 单题不带题号录入：整题内容可直接去除题号进行录入，该方式合规。

2. 题号与原文完全一致

    - 单题场景：题干、答案、解析无题号也合规；

    - 若内容自带题号，答案、解析题号必须和原题题干题号保持一致。

3. **多小题仅保留小题号**

    - 答案、解析题号和题干小题号一一对应，避免答案和题干题号错乱歧义；

    - 示例：原题小题号 13、14、15，可统一重新编号为 1、2、3 录入，但必须保证**题干、答案、解析题号匹配无误**。
