# 化学方程式识别提示词

化学方程式要求：

1. 严禁使用 KaTeX 以外的公式表达方式（如 MathML、Unicode 字符拼接、纯文本下标等），所有公式和化学式必须且只能使用 KaTeX 语法，前后用 `$` 包裹；
2. 化学式使用 `\ce{}` 宏表达（基于 mhchem 扩展），如 `$\ce{H2O}$`、`$\ce{CaCO3}$`；
3. **严禁使用 `\pu{}`**（部分平台如百度系统不支持该宏，会渲染失败），纯物理量和单位改用 `\mathrm{}` 包裹单位，并用 `\,` 细空格连接数字与单位：
   - 示例：`$0.1\,\mathrm{mol\cdot L^{-1}}\,\ce{HCl}$`、`$9.8\,\mathrm{m//s^2}$`（单位中斜杠可用 `//` 或 `\cdot` 表达）；
   - **严禁将带下标/上标（如化学式中的 H₂O、CO₂ 等）的内容与单位混合书写**，化学式必须用 `\ce{}` 表达，与单位用 `\,` 分开；
   - 正确做法：化学式使用 `\ce{}`，物理量单位使用 `\mathrm{}`，两者用 `\,` 连接书写；
   - ❌ 错误写法：`$\pu{22.4L H2O}$`（H2O 中的 "2" 不会显示为下标，且百度系统不支持 `\pu`）
   - ✅ 正确写法：`$22.4\,\mathrm{L}\,\ce{H2O}$`
   - ❌ 错误写法：`$\pu{0.1mol/L HCl}$`
   - ✅ 正确写法：`$0.1\,\mathrm{mol\cdot L^{-1}}\,\ce{HCl}$`
   - 类似地，`$\pu{44.8L CO2}$` 应写成 `$44.8\,\mathrm{L}\,\ce{CO2}$`；
   - 选项题示例：`A. $0.1\,\mathrm{mol\cdot L^{-1}}\,\ce{HCl}+0.1\,\mathrm{mol\cdot L^{-1}}\,\ce{NaCl}$`；
4. 化学方程式中反应条件写在 `[]` 中，气体符号用 `^`，沉淀符号用 `v`，如：
   - `$\ce{2H2 + O2 ->[点燃] 2H2O}$`
   - `$\ce{CaCO3 ->[高温] CaO + CO2 ^}$`
   - `$\ce{Fe + CuSO4 -> FeSO4 + Cu v}$`
5. 可逆反应使用 `<=>` 或 `<=>[条件]`，如 `$\ce{N2 + 3H2 <=>[高温高压][催化剂] 2NH3}$`；
6. 离子方程式同样使用 `\ce{}`，如 `$\ce{Ag+ + Cl- -> AgCl v}$`；
7. 电离方程式使用 `\ce{<=>}`，如 `$\ce{CH3COOH <=> CH3COO- + H+}$`；
8. 电极反应式，如 `$\ce{Zn - 2e- -> Zn^2+}$`；
9. 热化学方程式需标注状态和焓变，状态用 `(g)` `(l)` `(s)` `(aq)`，焓变用 `\Delta H`，如：
   `$\ce{2H2(g) + O2(g) -> 2H2O(l)}$，$\Delta H = \pu{-571.6 kJ//mol}$`；
10. 有机物结构简式：化学式部分用 `\ce{}`，如 `$\ce{C2H5OH}$`、`$\ce{CH3COOH}$`；
11. 氧化态/化合价标注使用 `\overset{}{}`，如 `$\overset{+2}{\ce{Fe}}$`；
12. 水合离子使用 `\cdot` 连接，如 `$\ce{Cu^2+ \cdot 4H2O}$`；
13. 希腊字母使用标准 LaTeX：`$\alpha$`、`$\beta$`、`$\gamma$`、`$\Delta$`、`$\delta$` 等；
14. 不使用 `\ce{}` 时，反应箭头可用 `\xrightarrow{条件}` 标注条件，如 `$\mathrm{2H_2 + O_2 \xrightarrow{\Delta} 2H_2O}$`；
15. 绝对不要使用 `\(` ... `\)` 包裹公式，必须使用 `$` ... `$`。
