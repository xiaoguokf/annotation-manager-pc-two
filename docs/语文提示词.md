# 语文提示词

语文题目在通用 OCR 规则之外，还需遵循以下要求：

1. **下三角加点（△）必须用 LaTeX 表达**。原稿在字的正下方画小三角表示加点时，**CSS 没有三角类名**（`rich-text-dot` 用的是 `text-emphasis-style`，渲染出来是**圆点**，不是三角），因此三角只能用 LaTeX：
   - 正确写法：`\(\underset{\tiny\triangle}{\text{字}}\)`
   - **每个被标记的字单独一段**，不合并、不省略、不换行。例如「西方译者」四字下方各有三角：
     `\(\underset{\tiny\triangle}{\text{西}}\)\(\underset{\tiny\triangle}{\text{方}}\)\(\underset{\tiny\triangle}{\text{译}}\)\(\underset{\tiny\triangle}{\text{者}}\)`
   - ❌ 错误：`\(\triangle\)`（裸三角命令）、`\(\text{△}\)`、直接输出字符 `△`
   - ❌ 错误：`<span class="rich-text-dot">西方译者</span>` —— 会渲染成字下圆点，与原文的三角不符
   - ❌ 错误：把多个字塞进一段，如 `\(\underset{\tiny\triangle}{\text{西方译者}}\)` —— 三角是逐字标记，必须拆成四段
   - ⚠️ 通用规则中「小三角归入加点族」的说法**对三角不适用**，三角一律以本条规定为准；「圆点 / 圆圈」才走加点类名。

2. **圆点加点用类名**（不要用三角的 LaTeX 写法）：字下方是分离的**小圆点** → `<span class="rich-text-dot">文字</span>`；**空心圆圈** → `rich-text-dot-open`；**实心大圆** → `rich-text-dot-filled`。

3. **加点字题型**（如「解释下列句子中加点的字」「给加点字注音」）：题干与正文中出现的加点字，必须**逐字**带上对应标记。加的是哪个字就标哪个字，不漏标、不扩到相邻的字、不把标点圈进去。

4. **下划线族按通用规则用类名**：普通下划线 `rich-underline`、波浪线 `rich-underline-wave`、虚线 `rich-underline-dashed`、双线 `rich-underline-double`。
   - 语文中「用波浪线画出下列句子」「在海龟背上画横线」这类指令，画的是**波浪线**，用 `rich-underline-wave`。
   - 被标记的句子要**完整包住**（含句中标点），一个连续标记只用一个 span，不要拆成几段。

5. **注音**：文中给汉字注音时用 `\(\overset{\text{拼音}}{\text{字}}\)`，如 `\(\overset{\text{méng}}{\text{蒙}}\)`。不要把拼音写成图片、也不要输出 `ruby` 标签。

6. **标点用全角**：中文标点一律使用全角（，。；：？！“”‘’《》——……），不要转成半角，也不要包进 LaTeX。

7. **古籍 / 文言文本的换行**：按语义分段保留，不要因版面折行而断句；注释行（如「〔1〕」「①」）单独成行。

8. 本文件未提到的样式（加粗、斜体、删除线、高亮、上下角标、作答横线等）按通用提示词执行。
